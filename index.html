01 // VISION & BACKGROUND

「ないなら作る」—— 量子計算を机の上へ

現在の量子コンピュータは、絶対零度近くの冷却装置や巨大な超伝導電磁石を必要とし、一部の大学や大企業に独占されています。クラウド経由でブラックボックスとして触るだけでなく、「物理的なハードウェアに自分の手で直接触れて実験できる環境を作りたい」という想いから本プロジェクトは始まりました。

人工的な強磁場の代わりにどこにでも存在する「地球磁場」を利用するEFNMR（地球磁場核磁気共鳴）方式を採用し、高専生の自作ハードウェアによる量子スピン操作と信号検出に挑んでいます。

02 // STORY & BREAKTHROUGH

泥臭いハードウェア実装とFID信号の観測成功

心臓部となるセンサーコイルは、外径48mmの塩ビ管に0.5mmのエナメル線（約250m）を2人がかりで1600回手作業で巻き上げました。また、9V電池の逆接で高価な超低歪オペアンプ（AD797BRZ）から煙を出して焼損させる痛恨のトラブルも経験しました。

数々のノイズやトラブルを乗り越え、ついにオシロスコープおよびPCへの取り込みにて、地球磁場におけるプロトンのラーモア周波数帯域（約2.04kHz）の正弦波およびFID（自由誘導減衰）信号の観測に成功しました。

03 // SYSTEM ARCHITECTURE

  • SENSOR 偏極・受信兼用コイル： 0.5mm 2UEWエナメル線 1600ターン手巻き（サンプル：精製水）
  • POWER & DRIVE 完全バッテリー駆動分極回路： 12V鉛蓄電池 ＋ NchパワーMOSFET (2SK4017) ＋ ファストリカバリーダイオード（サージ保護）
  • CONTROL ミリ秒シーケンス制御： M5Stack CoreS3 Lite ＋ ミニリレーユニット（50msデッドタイムによる回路保護）
  • ANALOG AMP 微小信号増幅回路： 超低歪低雑音オペアンプ (AD797BRZ) ＋ アルミシールドケース
  • DSP & FPGA 信号解析・パルス制御： 96kHz/24-bit USBサウンドカード ＋ Python (FFT解析) / Tang Nano 20K (Verilog HDL)
